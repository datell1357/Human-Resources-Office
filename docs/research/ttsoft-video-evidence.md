## 검토 방법과 범위

유튜브 페이지에서 제목·채널·게시일·설명란을 확인하고, 전체화면으로 아래 시점의 영상 프레임을 직접 검토했다. 설명란은 비어 있고 플레이어는 자막 사용 불가로 표시됐다. 음성 전사는 확보하지 않았다. 전 구간의 모든 프레임을 검사한 것이 아니라 주요 시점을 표본 검토한 결과다.

영상에 표시되는 계정 값·비밀번호는 기록하지 않았다. 원본 영상이나 인증정보가 노출된 스크린샷도 저장소에 포함하지 않았다. 사이트 링크를 실제로 열거나 가입·로그인·게시 작업을 수행하지 않았다.

아래의 **화면 확인**은 영상에 해당 UI 또는 결과가 보인다는 뜻이다. 프로그램을 직접 실행해 재현했다는 뜻은 아니다. **공급자 설명**은 영상 오른쪽 설명문에 나오는 주장으로, 현재 제품의 성능이나 지원 여부를 보증하지 않는다.

## UI 항목의 정확한 해석

- 탭: 설정 / 글 보기·글 작성 / 로그.
- 실행 설정: 분류 선택, 자동가입 가능 사이트만 사용하는 선택지, 작성글 선택, 시작·중지.
- 설정 표: 번호, 이름, 링크, 아이디, 비밀번호, 분류, 비고, 분 단위 딜레이.
- 설정 화면에서 공통 작업 딜레이는 30분, 여러 개별 딜레이는 0으로 표시된다. 이 값들이 사이트 간 간격인지 전체 순회 간격인지, 상호 우선순위가 무엇인지는 영상만으로 확정할 수 없다.
- 계정 초기화 버튼이 보인다는 사실과 실제 원격 서비스 계정을 삭제한다는 것은 별개다.
- 제목 표시줄에는 사용자와 남은 일수 형태의 정보가 보인다. 라이선스 기간 표시일 가능성은 있지만 실제 인증 방식과 판매 정책은 미확인이다.
- 오른쪽의 큰 설명문과 결과 확인용 외부 브라우저는 프로그램의 탭으로 분류하지 않는다.

## 추가 확인이 필요한 항목

1. 게시글 저장 슬롯 수와 제목·본문·링크·첨부의 정확한 계약.
2. 시작·중지 시 진행 중 요청의 처리와 재시작 지점.
3. 작업 딜레이와 개별 딜레이의 관계, 반복 실행 및 예약 지원.
4. 실패 이유 분류, 재시도 한도, 중복 게시 방지와 결과 재검증.
5. 계정 보관 암호화, 접근 권한, 로그 마스킹, 백업·복구.
6. 사이트별 인증·추가 확인 요구가 발생했을 때 사람에게 넘기는 동작.
7. 공급자 목록 갱신의 범위와 실패 시 복구 방법.
8. 2026년 현재 제품 제공 여부·가격·지원 대상·운영체제 호환성.
