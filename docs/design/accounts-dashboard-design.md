# accounts.txt 접속 대상 화면 설계

초안의 기본 화면은 로컬 `accounts.txt`를 읽어 활성 대상, 제외 대상, 오류 행을 한눈에 구분하는 데 목적이 있다.

## 디자인 시스템

- 배경: 흰색 `#ffffff`, 보조 배경 `#f4f6f8`
- 내비게이션: 짙은 남색 `#152437`
- 강조색: 초록 `#1d8a6a`, 경고는 주황, 오류는 빨강
- 구조: 왼쪽 내비게이션, 가운데 요약과 대상 표, 오른쪽 선택 상세, 하단 파일 상태
- 표: 상태, 참조 주소, 계정, 판단, 메모. 비밀번호는 어느 화면에서도 표시하지 않는다.
- 핵심 동작: 행 선택, 상태별 필터, `accounts.txt` 다시 읽기

시안 이미지는 [`accounts-dashboard-concept.png`](accounts-dashboard-concept.png)이며, 실제 구현은 텍스트와 컨트롤을 코드로 렌더링한다.
